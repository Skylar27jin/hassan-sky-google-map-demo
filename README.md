# hassan-sky-google-map-demo

This is a demo for integrating Google Map to React. It's working now!


How to Run?

Install Node.js on the Internet(Google Search or ChatGPT)


After Installation, check whether it's working by...
```
node -v
npm -v
```

Install necessary dependency before start FrontEnd
```
npm install
```

Start FrontEnd:
```
npm run dev
```





Create a empty React-TS project with the help of VITE:
```
npm create vite@latest my-app -- --template react-ts
```
